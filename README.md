 To-Do list Dashboard — Mini Project RevoU

Dashboard produktivitas sederhana yang dirancang untuk membantu pengguna tetap fokus, mengatur tugas harian, dan mengakses tautan penting dalam satu tempat.

🌐 Demo Website: https://iksan-28.github.io/CodingCamp-12October2026-ikhsan/

Tentang Proyek

To-Do list Dashboard adalah aplikasi berbasis web yang dikembangkan sebagai bagian dari mini project RevoU. Website ini menggabungkan beberapa fitur produktivitas dalam satu tampilan yang sederhana dan mudah digunakan.

Proyek ini dibuat sebagai sarana belajar dan mengembangkan keterampilan dasar dalam pembuatan website menggunakan HTML, CSS, dan JavaScript.

✨ Fitur Utama

⏱️ Focus Timer — Timer 25 menit untuk membantu pengguna lebih fokus saat belajar atau mengerjakan tugas.

✅ To-Do List — Menambahkan dan mengatur daftar tugas harian.

🔗 Quick Links — Menyimpan tautan penting agar lebih mudah diakses.

🌙 Light & Dark Mode — Mengubah tampilan website ke mode terang atau gelap.

✏️ Mode Edit — Mengubah elemen dashboard yang didukung oleh fitur edit.

📱 Desain Responsif — Dirancang agar nyaman digunakan di berbagai ukuran layar.

🛠️ Teknologi yang Digunakan

HTML5 — Membuat struktur halaman website.

CSS3 — Mengatur tampilan, tata letak, dan desain website.

JavaScript — Menambahkan fungsi dan interaksi pada website.

Git & GitHub — Mengelola dan menyimpan kode proyek.

GitHub Pages — Mempublikasikan website agar dapat diakses secara online.
